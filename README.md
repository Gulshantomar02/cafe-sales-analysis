# Cafe Sales Analysis

A beginner-level data analytics project based on cafe sales data.

## Project Overview

In this project, I cleaned and analyzed cafe sales data using Python, Pandas, and Plotly to find useful sales and business insights.

## Tools Used

- Python
- Pandas
- NumPy
- Plotly
- Jupyter Notebook

## Analysis

- Data Cleaning
- Missing Value Handling
- KPI Calculation
- Product Performance Analysis
- Monthly Sales Analysis
- Payment Method Analysis
- Location Analysis
- Data Visualization

## Key Findings

- Total Revenue: 88,952
- Total Transactions: 10,000
- Total Units Sold: 30,141
- Average Transaction Value: 8.93
- Coffee sold the most units.
- Salad generated the highest product revenue.
- June had the highest monthly revenue.

## Files

- `Cafe_Sales_Analysis_project.ipynb` — Jupyter Notebook containing the analysis
- `cleaned_cafe_sales.csv` — Cleaned dataset
